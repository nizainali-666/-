02 — Method

先建资产，再出镜头

这是我和「抽卡式做法」最大的区别： 先把人物和空间定义清楚，再去生成镜头。

01

资产库先行

每个项目先建「人物 / 场景 / 道具」三个资产库，再拆镜头。素材有出处，返工有依据。

02

角色设定卡

A-POSE 四视图锁定脸、体型、戏服——让角色在 20 个镜头里是同一个人。

03

场景设定图

俯视 45° 全屋蓝图，标注门窗、家具、光源位置，保证跨镜头空间关系不穿帮。

03 — Range

同一套工作流，可以调到完全不同的视觉气质——这决定了能接什么样的活。

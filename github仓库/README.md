# AIGC 视频作品集

一个纯静态的单页作品集网站。24 天内独立完成 6 支 AIGC 成片，覆盖剧本、分镜、角色设定、图生视频到剪辑的完整链路。

## 页面结构

| 区块 | 内容 |
|---|---|
| 首屏 | 身份说明 + B 站入口 |
| 01 作品 | 6 支成片，2 列 3 行 |
| 02 方法 | 资产库工作流（人物 / 场景 / 道具 / 关键帧）+ 6 个项目的资产库截图 |
| 03 能力 | 三种视觉风格：3D 国漫 / 新海诚 / 真人 |
| 04 流程 | 剧本 → 分镜 → 资产 → 提示词 → 生视频 → 剪辑 |
| 05 联系 | 电话 / 邮箱 / B 站 / 小红书 |

## 技术

- **单文件 HTML**，CSS 与 JS 全部内联，无构建流程、无第三方依赖
- 纯静态，可直接部署到 GitHub Pages / Netlify / Cloudflare Pages
- 响应式布局，适配桌面、平板与手机
- 图片全部相对路径引用，支持部署在任意子目录

## 目录

```
index.html          页面本体
assets/
  hero.jpg          首屏背景
  work-*.jpg        6 支作品的封面
  asset-*.jpg       6 个项目的资产库截图
  style-*.jpg       3 种风格的代表图
```

## 本地预览

双击 `index.html` 即可，或起一个本地服务：

```bash
python -m http.server 8000
```
